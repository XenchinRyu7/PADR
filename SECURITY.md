# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

The PADR team takes the security of autonomous development runners seriously. If you discover a security vulnerability (such as unintended credential exposure, path traversal, or command injection risk), please report it responsibly.

### How to Report
- **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.
- Please email the maintainers directly or use [GitHub Private Vulnerability Reporting](https://github.com/XenchinRyu7/PADR/security/advisories/new).
- Include details such as:
  - Description of the vulnerability and attack vector
  - Steps to reproduce or proof-of-concept
  - Affected operating systems or CLI flags

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- A fix will be developed and reviewed in a private branch before release.
- Public disclosure will occur following the release of the security patch.
